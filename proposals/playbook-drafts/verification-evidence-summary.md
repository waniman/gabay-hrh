# Verification 01: evidence-synthesis claims (V01 to V23)

Mode: verify. Checked 2026-11-11 against the sources named in the claim list only.

How the sources were opened:
- Cochrane Handbook chapters, the PRISMA extensions page, the Cochrane RRMG page and the GRADE handbook: live web pages, downloaded and searched as text.
- Journal articles: full text from Europe PMC (fullTextXML). Hultcrantz 2017 came from the PMC author manuscript, via NCBI efetch.
- Stevens 2025: also the published-version PDF in the White Rose repository.
- Grant and Booth 2009 and Nussbaumer-Streit 2025: abstract only (PubMed record via Europe PMC). The publisher sites returned 403.
- JBI Manual: the Confluence page through its REST API.
- Publisher PDFs (BMJ, BMJ EBM, BMC/Springer, Elsevier, Wiley) returned 403 or a script challenge. So printed page numbers could not be checked except where stated. Locations are given by section, table or numbered heading.
- The PubMed MCP tools were not available in this session, so I used the Europe PMC REST API and NCBI E-utilities instead.
