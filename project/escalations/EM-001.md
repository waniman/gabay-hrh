## Options

1. **Option A. Five work packages.** WP1 starts now. WP2 to WP5 are created as planned and wait for the pilot's data. Each missing playbook is drafted and approved before its work package starts. Consequence: every output promised in the URC proposal is on the plan, and nothing is spent on them until they start.
2. **Option B. Option A plus WP6, the ethics package and instruments.** WP6 would revise the ethics application and complete the data collection instruments, starting now, on the revision playbook. Consequence: it uses run time alongside WP1. It fits only if the clearance is still pending. In the Drive folder, "1a. WISN calculation templates" and "ICF forms" hold almost no content (1 KB each).
3. **Option C. WP1 only.** The pilot's outputs are added later, each by its own memo. Consequence: a shorter frame now, and four more scope memos in 2027.

## Recommendation

Option A. It records every output the funded pilot committed to and costs no run time until each starts. Choose Option B if the ethics clearance is not yet secured and the team should help with it; the status is not recorded in the folder.
