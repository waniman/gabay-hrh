description: Show where the project stands: each work package's stage, what waits on the lead, last checkpoint, outcomes observed
---

1. Run `python3 tools/team.py status` and `python3 tools/team.py memo list --open`.
2. Tell the lead, in seven lines or fewer, plus one line for each work package: the stage and status of each work package and what it waits for, what moved in the last run, what waits on them (memo ids and gates, with the issue of each), comments awaiting approval or edits, the last checkpoint, outcomes observed so far, the last health check and its overall flag, and what happens next. Give the master copy of a work package only when it is outside the repository.
